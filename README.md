# TotBagss Premium Child Theme

Bu depo, TotBagss e-ticaret sitesi için özelleştirilmiş bir WordPress Astra Child Theme içeriğini barındırmaktadır.

## İçerik

- `style.css`: Hero bölümü, kategori barı, hikaye bölümü ve WooCommerce özelleştirmelerini içeren CSS kodları.
- `functions.php`: Ürün karusel kısa kodu, font yükleme, loop özelleştirmeleri (rozetler, sayaçlar), görsel optimizasyonu ve hesap sayfası düzenlemelerini içeren PHP kodları.

## Nasıl Kullanılır?

1. WordPress sitenizin `wp-content/themes/` dizininde `astra-child` adında yeni bir klasör oluşturun.
2. Bu depodaki `style.css` ve `functions.php` dosyalarını o klasöre yükleyin.
3. WordPress panelinden **Görünüm > Temalar** bölümüne gidin ve **Astra Child** temasını etkinleştirin.

### Karusel Kullanımı
Yeni gelen ürünler karuselini herhangi bir sayfada göstermek için şu kısa kodu kullanabilirsiniz:
`[totbagss_carousel]`

## Özellikler

- **Hero Alanı:** Premium tasarımlı, Bruno Ace SC fontlu giriş alanı.
- **Dinamik Sayaçlar:** Kargo gönderim süresini gösteren canlı sayaçlar.
- **Görsel Optimizasyonu:** WebP desteği ve lazy loading aktif.
- **Premium Hesap Sayfası:** Müşteriler için özelleştirilmiş profil ve sipariş takip ekranları.
